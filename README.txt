심장가까이 정적 HTML 완성본

구성 파일
- index.html : 메인 화면
- style.css  : 디자인 및 모바일 반응형 스타일
- app.js     : 검색, 지역 연동, 상세보기 기능
- data.js    : 의료기관 데이터

사용 방법
1. 네 파일을 같은 폴더에 둡니다.
2. index.html을 더블클릭하면 인터넷 브라우저에서 실행됩니다.
3. 웹호스팅 또는 GitHub Pages에 올릴 때도 네 파일을 같은 경로에 업로드합니다.

데이터 기준
- 의료기관 기본정보: 2026년 6월
- 진료과목 자료: 2026년 3월
- 심장초음파 및 실제 진료 일정은 의료기관에 최종 확인해야 합니다.
